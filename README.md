# Wireshark Network Traffic Analysis

## 📌 Project Overview

This project demonstrates the practical use of **Wireshark** for capturing, filtering, and analyzing network traffic.

The objective was to understand how network packets are transmitted across a local network and how protocols such as **TCP, DNS, HTTP, and TLS** appear during real-time network communication.

The project also focuses on understanding the **TCP 3-way handshake**, identifying encrypted and unencrypted traffic, and understanding the security risks associated with transmitting information over unencrypted HTTP connections.

## 🎯 Objectives

The main objectives of this task were:

- Install and configure Wireshark.
- Capture live network traffic from a local network interface.
- Analyze captured packets using Wireshark display filters.
- Analyze DNS traffic.
- Analyze TCP traffic.
- Understand the TCP 3-way handshake.
- Identify HTTP and HTTPS traffic.
- Understand the security risks of unencrypted HTTP communication.
- Export captured traffic as a `.pcap` file.
- Document network-analysis findings.
- Follow ethical and authorized network-monitoring practices.
